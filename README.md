# X3 ToDo Sync

指定したObsidianノートの未完了タスクを、親・子・孫の階層を保持してXteink X3の「ToDo」アプリへ最大30件送ります。X3で完了した1行をFirebase中継API経由で元ノートの`[x]`へ反映できます。

## 使い方

1. `x3-todo.txt` を含むSecret Gistを作成する
2. GitHubでClassic personal access tokenを作り、権限は `gist` だけにする
3. Obsidianの「設定 → コミュニティプラグイン」で `X3 ToDo Sync` を有効にする
4. プラグイン設定にGist IDとGitHub Gistトークンを入力する
5. 双方向同期を使う場合は、管理者から渡されたRelay URLと接続キーを入力する
6. 同期対象ノートに未完了タスクを書く

```markdown
- [ ] 買い物に行く
- [ ] 資料を確認する
```

ノート保存から3秒後に自動同期します。「今すぐ同期」ボタンまたはコマンドパレットから手動同期もできます。X3からの完了通知は起動時・同期時・5分間隔で確認します。

## X3側

- ホームの「ToDo」を開くと、端末内に保存した前回データを即座に表示する
- 上下ボタンでToDoを1行ずつ選択する
- 決定ボタン短押しで選択した1行だけを完了する
- 決定ボタン長押しで最新データを手動取得し、保留中の完了通知を再送する
- 天気の更新に成功した時にもToDoを同時取得する
- 1ページ6件、最大30件。選択行に合わせてページを自動で切り替える
- Markdownのインデントを最大3段階まで保持し、X3でも子ToDoを右へずらして表示する

## 注意

同期先はURLを知っている人が読めるSecret Gistです。専用ノートに機密情報・個人情報を書かないでください。

GitHub/GistトークンはX3へ送信しません。FirebaseにはToDo本文ではなく、完了対象を示す16桁IDだけを一時保存します。
