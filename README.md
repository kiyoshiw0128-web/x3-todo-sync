# X3 ToDo Sync

指定したObsidianノートの未完了タスクを、Xteink X3の「ToDo」アプリへ最大30件送るプラグインです。

## 使い方

1. `x3-todo.txt` を含むSecret Gistを作成する
2. GitHubでClassic personal access tokenを作り、権限は `gist` だけにする
3. Obsidianの「設定 → コミュニティプラグイン」で `X3 ToDo Sync` を有効にする
4. プラグイン設定にGist IDとGitHub Gistトークンを入力する
5. `01_ToDo/X3待受.md` に未完了タスクを書く

```markdown
- [ ] 買い物に行く
- [ ] 資料を確認する
```

ノート保存から3秒後に自動同期します。「今すぐ同期」ボタンまたはコマンドパレットから手動同期もできます。

## X3側

- ホームの「ToDo」を開くと、端末内に保存した前回データを即座に表示する
- 決定ボタンで最新データを手動取得する
- 天気の更新に成功した時にもToDoを同時取得する
- 1ページ6件、最大30件。上下ボタンでページを切り替える

## 注意

同期先はURLを知っている人が読めるSecret Gistです。専用ノートに機密情報・個人情報を書かないでください。
